# The "God-Tier" Web Design, Responsiveness & 3-Engine (SEO/AEO/GEO) Master Prompt

Use this master prompt with any advanced AI (Antigravity, Claude 3.7 Sonnet, ChatGPT o3-mini/GPT-4o, Gemini 1.5 Pro) to build or redesign any website to the absolute highest aesthetic, responsive, and search-ranking standards in the world.

---

## 📋 The Copy-Paste Master Prompt

```markdown
Act as the world's premier web designer, technical architect, and search engine optimization authority (SEO, AEO, and GEO). I want you to build / rebuild our website to an elite, world-class standard ("God top notch") that feels like it was designed by Apple, Pentagram, or Studio McGee, while outranking all regional competitors and winning AI-search citations.

Here are the business and project parameters:
- Business Name: [INSERT BUSINESS NAME, e.g., Aspen II Homes]
- Industry / Niche: [INSERT NICHE, e.g., Custom & Semi-Custom Home Builder]
- Primary Location / Market: [INSERT REGION, e.g., Tehachapi & Kern County, CA]
- Core Offerings / Products: [INSERT 3-6 PRODUCTS/SERVICES WITH SPECS & PRICES]
- Years in Business / Founded Date: [INSERT FOUNDING YEAR, e.g., 1994 / 31 Years]
- Verifiable Credentials & Trust Points: [INSERT LICENSE #, BBB RATING, REVIEWS, AWARDS]
- Canonical Contact Info: [INSERT CANONICAL PHONE, EMAIL, AND PHYSICAL ADDRESS]

Execute the build following these six mandatory pillars:

### 1. LUXURY EDITORIAL VISUAL DESIGN & TYPOGRAPHY
- Implement an editorial aesthetic combining a high-character display serif for headlines (e.g., Newsreader, Playfair, Cormorant) with a crisp, modern geometric sans-serif for UI and data (e.g., Plus Jakarta Sans, Inter).
- Enforce fluid typography using CSS `clamp()` for all heading levels (H1, H2, H3) and constrain paragraph measures to 55–75 characters.
- Curate a cohesive, region-authentic 5-color palette:
  - Deep Anchor Ink (for high-contrast dark sections)
  - Warm Alabaster / Bone (page background)
  - Rich Mineral Accent (Terracotta, Copper, Emerald, or Navy for primary CTAs)
  - Organic Muted Secondary (Sage, Sand, or Slate for borders and badges)
  - Subtle Gold / Metallic (for verification stars and credentials)
- Apply hairline micro-borders (rgba 8–12%), frosted glass navigation with backdrop blur (blur 18px), and layered soft elevation shadows.

### 2. FULL MULTI-DEVICE RESPONSIVENESS (MOBILE, TABLET, DESKTOP)
- Mobile-First Lead Conversion (< 768px):
  - Provide a fixed floating Mobile Quick-Action Dock at the bottom of the viewport with a 1-tap direct dial call button and a 1-tap consultation/quote button.
  - Deliver an animated hamburger toggle opening a full-height slide-over drawer with blur backdrop and quick contact cards.
  - Enforce strict minimum 48px × 48px touch targets on all interactive controls.
- Tablet Balance (768px – 1024px):
  - Ensure all 3-column and 4-column grids (bento, products, steps, footer) fold gracefully into balanced 2-column layouts without awkward gaps or squished cards.
- Desktop Precision (> 1024px):
  - Sticky frosted header with scroll-state transition, 4-column trust metric ticker, 4-column bento showcase, and 3-column product cards.

### 3. REPUTATIONAL FRONT-LOADING & HARD PROOF ENGINE
- Place a Credibility Top-Ticker Bar and Trust Matrix directly above the fold displaying verified numbers: years in business, license numbers, permit totals, dollar volume, and accreditation ratings.
- Eliminate all unproven stock superlatives (no empty claims like "unparalleled quality" without attaching a hard specification, date, or named testimonial).
- Integrate an explicit, written multi-tier Guarantee or Warranty with a scheduled post-purchase check-in protocol and direct service request portal.

### 4. INTERACTIVE LEAD-CAPTURE ENGINES
- Build an interactive Cost & Payment Estimator widget:
  - Real-time dropdowns/toggles for location/submarket, model/service tier, and optional upgrades.
  - Live calculation showing Estimated Total Investment and Estimated Monthly Payment.
  - Direct "Lock in Estimate & Book Consultation" button that pre-populates the inquiry form.
- Interactive Product / Plan Spec Modals:
  - Clicking any card opens a clean architectural or technical specification modal with dimensions, inclusions, and a quote request action.
- Live Status Filtering:
  - Instant filter buttons allowing users to filter items by availability or category.

### 5. TOTAL 3-ENGINE RETRIEVAL DOMINATION: SEO · AEO · GEO
- Search Engine Optimization (SEO):
  - Semantic HTML5 structure (single H1, logical H2/H3s, schema breadcrumbs).
  - Hyperlocal geographic keyword targeting in title, description, and copy.
  - Complete Open Graph, Twitter Cards, canonical link, and geo tags (geo.region, geo.placename, geo.position, ICBM).
  - Create a production-grade `sitemap.xml` with image namespaces.
- Answer Engine Optimization (AEO):
  - Minimum 8–10 FAQ questions matching exact natural search queries ("How much does X cost?").
  - Under each heading, provide an immediate 40–60 word direct factual answer paragraph engineered for Google Featured Snippets and People Also Ask.
- Generative Engine Optimization (GEO):
  - Deliver machine-extractable, unambiguous entity statements for AI models (Gemini, ChatGPT, Perplexity, Claude, Apple Intelligence).
  - Create an `llms.txt` plain markdown fact sheet at the domain root summarizing canonical facts.
  - Create a `robots.txt` explicitly permitting AI search bots (GPTBot, OAI-SearchBot, Google-Extended, ClaudeBot, PerplexityBot, Applebot-Extended).
  - Generate a comprehensive Schema.org JSON-LD `@graph` containing `Organization`, `LocalBusiness`, `hasCredential`, `hasOfferCatalog`, `Product`, `Service`, `FAQPage`, `BreadcrumbList`, and `WebSite`.

### 6. ZERO-BLOAT PERFORMANCE & CORE WEB VITALS
- Build using clean, semantic, modern HTML5, CSS custom properties, and lightweight vanilla JavaScript.
- Avoid multi-megabyte JavaScript frameworks for static promotional sites.
- Apply explicit width and height attributes on all images to prevent Cumulative Layout Shift (CLS < 0.02).
- Eagerly load and add `fetchpriority="high"` on the hero image; lazy-load all below-the-fold assets to achieve Largest Contentful Paint (LCP < 1.8s).
```
