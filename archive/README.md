# Archive

Files kept for reference only. Nothing in this folder is used by the live
site, and `.vercelignore` keeps the whole folder out of every deployment.

- `reports-2026-09/`: audit and optimization reports written on 2026-09-16 and
  2026-09-17. Most describe the earlier `hshomeshub.site` real-estate site, not
  the current Aspen II Homes site, so don't treat them as current state. The
  current state lives in `.ai/PROJECT_STATE.md`.
- `unused-images/`: generated renders, `extra_photos/` and a JPEG poster that no
  page references. The site uses the WebP files in `assets/images/` and
  `media/aspen-website-open-poster.webp`.
- `old-project/info.txt`: listing data for 585 N Wendy Dr, Newbury Park, from
  the earlier real-estate site.
